# Roadmap

## PR 1 — Foundation hardening
- Add React component tests for diagnostic and quiz progression.
- Add ESLint and formatting checks.
- Add automated source-integrity audit (URL presence + stale review date warning).
- Improve offline shell and installability icons.

## PR 2 — Weight Lab 2.0
- Registration-certificate style cards.
- User must identify which field matters before calculating.
- Add axle/train-weight teaching where supported by authoritative sources.
- Add generated practice scenarios with property-based tests.

## PR 3 — Load & stability visual lab
- Top-down trailer with draggable load blocks.
- Explain centre of mass, load placement, stability and securing principles without inventing universal nose-weight numbers.
- Scenario animations for crosswind, braking and oscillation.

## PR 4 — Coupling & safety-control coach
- Step-by-step coupling / uncoupling practice.
- Oral examiner mode: prompt -> speak/think -> reveal audit checklist.
- Random safety-control prompts reflecting Trafikverket's current list.

## PR 5 — Experienced-driver refresh
- Expand current B curriculum checks using current authoritative sources.
- Adaptive review by category + confidence.
- "Changed / easy to forget" cards with source dates; do not claim a rule changed unless history is verified.

## PR 6 — Exam-ready bank
- 150+ reviewed questions.
- Syllabus coverage dashboard.
- 60-question, 40-minute simulator; one correct answer per question; 44/55 scoring presentation with five unscored items modelled without revealing which are unscored.
- Result breakdown and next-study plan.

## PR 7 — Driving test prep
- Manoeuvre practice flows.
- Vehicle-requirement checklist for test day.
- Safety-control rehearsal and printable checklist.

## Later
- Optional voice mode.
- Import a user's own vehicle/trailer registration data only if a safe and maintainable official data route is available.
- Multi-device sync is intentionally deferred; local-first is sufficient for MVP.
