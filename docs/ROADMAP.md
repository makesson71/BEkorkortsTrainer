# Roadmap

## Done
- Foundation PWA, diagnostic, lessons, Weight Lab, source registry.
- PR 1 — Content hygiene and current BE rule sources.

## PR 2 — Begreppslabbet + registreringsbevis (this PR)
- Structured concept model for BE weight, trailer, licence and certificate terms.
- Interactive visualizer: totalvikt stays fixed, bruttovikt moves with load.
- Licence versus technical limits.
- Original registration-certificate trainer.
- Concept drills and “Blanda inte ihop” pairs.
- Weight Lab ⓘ help into concept explanations.

## PR 3 — Road signs and “what changed since I took my licence?”
Intentionally deferred. Not in this PR.
- Traffic-rule history timeline with verified change dates only.
- High-value B refresher for drivers licensed decades ago.
- Road-sign catalogue / sign recognition — not started here.

## PR 4 — Load & stability visual lab
- Top-down trailer with draggable load blocks.
- Centre of mass, load placement, stability and securing principles without inventing universal nose-weight numbers.
- Scenario animations for crosswind, braking and oscillation.

## PR 5 — Coupling & safety-control coach
- Step-by-step coupling / uncoupling practice.
- Oral examiner mode: prompt -> speak/think -> reveal audit checklist.
- Random safety-control prompts reflecting Trafikverket's current list.

## PR 6 — Exam-ready bank
- 150+ reviewed questions.
- Syllabus coverage dashboard.
- 60-question, 40-minute simulator; one correct answer per question; 44/55 scoring presentation with five unscored items modelled without revealing which are unscored.
- Result breakdown and next-study plan.

## PR 7 — Driving test prep
- Manoeuvre practice flows.
- Vehicle-requirement checklist for test day.
- Safety-control rehearsal and printable checklist.

## Later
- Optional voice mode.
- Import a user's own vehicle/trailer registration data only if a safe and maintainable official data route is available.
- Multi-device sync is intentionally deferred; local-first is sufficient for MVP.
- Backend/accounts/cloud sync remain out of scope.
