# BE-körkortsTrainer Sverige

Mobilanpassad träningsapp för svenskt BE-körkort, byggd för förare som redan har B-körkort men vill fräscha upp modern teori och träna BE-specifika moment pedagogiskt.

Projektet fokuserar på förståelse snarare än memorering: vikter och fordonskombinationer, lastsäkring, koppling, trafiksäkerhet, risker och repetition av relevant B-teori.

Se `docs/PRODUCT_SPEC.md`, `docs/BE_SYLLABUS_MAP.md` och `AGENTS.md` för mål, kursplanstäckning och utvecklingsregler.
